# Output Formats — `/pdlc:continue`

Форматы вывода для всех точек жизненного цикла команды: начало работы,
полный цикл одной задачи, при падении тестов с автоисправлением, при quality
review с улучшением, при блокировке (прерывание), итоги сессии.

---

